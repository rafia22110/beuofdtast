# Contributing to OculoFlow / Beuofdbak (Alpha v3.0)

Thank you for your interest in **OculoFlow (`Beuofdbak`)** — an open-source (MIT) clinical & research initiative exploring non-invasive smartphone pupillometry and closed-loop neuro-biofeedback.

## 📱 How to Contribute to the Mobile Camera Compatibility Study (60 Seconds)
Because smartphone front-facing cameras vary in frame rate (FPS), rolling shutter exposure, and IR/visible spectrum contrast across dark and light irises, our top priority in **Alpha v3.0** is mapping device compatibility:

1. Open **[https://beuofdbak.vercel.app/](https://beuofdbak.vercel.app/)** on your smartphone (iOS Safari or Android Chrome).
2. Complete the 60-second 3-stage optical protocol:
   - **Stage A (20s)**: Resting Baseline (`מנוחה`)
   - **Stage B (20s)**: Cognitive Load (`מאמץ קוגניטיבי`)
   - **Stage C (20s)**: Photopic Light Reflex (`רפלקס אור בוהק`)
3. Submit your anonymous device compatibility telemetry. All submissions are strictly anonymous, zero-targeted, and automatically deleted after hardware calibration verification.

## 💻 Code Contributions & Pull Requests
1. Fork the repository (`https://github.com/rafia22110/Beuofdbak`).
2. Create a feature branch (`git checkout -b feat/subpixel-iris-edge`).
3. Verify TypeScript compilation (`npm run lint && npm run build`).
4. Open a Pull Request under the **MIT License**.
